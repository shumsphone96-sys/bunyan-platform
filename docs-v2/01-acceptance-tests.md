# اختبارات قبول لوحة الإدارة V2

لا تُدمج لوحة الإدارة الجديدة في `main` قبل نجاح جميع البنود التالية عمليًا.

## الدورة الأولى: الدخول والجلسة والطلبات

- [ ] فتح `admin-v2/index.html` يعرض صفحة الدخول فقط.
- [ ] البريد أو كلمة المرور الخاطئان يعرضان رسالة مفهومة دون شاشة بيضاء.
- [ ] بيانات المدير الصحيحة تفتح لوحة الإدارة.
- [ ] تحديث الصفحة أثناء الجلسة يعيد فتح اللوحة بعد التحقق من `/api/auth/me`.
- [ ] زر الخروج يمسح الجلسة ويعيد صفحة الدخول.
- [ ] انتهاء الجلسة يعيد المستخدم للدخول دون تعليق الواجهة.
- [ ] لوحة المؤشرات تعرض أرقام الخادم الحقيقية.
- [ ] طلبات المساعدة تظهر من `/api/help/requests`.
- [ ] طلبات المشاركة تظهر من `/api/requests`.
- [ ] تغيير حالة طلب مساعدة يُحفظ ويظل صحيحًا بعد التحديث.
- [ ] تغيير حالة طلب مشاركة يُحفظ ويظل صحيحًا بعد التحديث.
- [ ] عدادات الطلبات الجديدة تتغير بعد تحديث الحالة.
- [ ] القائمة الجانبية تعمل على الهاتف ولا تتداخل مع قائمة الموقع العام.
- [ ] فشل النطاق الأساسي ينتقل إلى نطاق Render الاحتياطي.
- [ ] مهلة الاتصال تعرض رسالة واضحة مع زر إعادة المحاولة.
